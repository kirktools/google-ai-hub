核心功能

专为 Google AI 订阅用户设计的省心体验，低频温和、开箱即用。

自动识别套餐，免手动配置

优先从 Google One 页面自动识别 Free / AI Plus / AI Pro / AI Ultra (5x / 20x) 及续费重置日，自动匹配对应权益卡片；未识别到时也支持设置页手动兜底。

一键静默同步 + 低频定时刷新

优先复用已打开标签，其余仅复用单个后台非激活标签页提取可见信息后立即关闭；支持每 1~12 小时低频自动更新与 3 分钟防抖冷却，打开看板即刻秒看。

8 大平台全景覆盖 + 手动校准

一站汇总 Google One、AI Studio、Flow、Colab、Gemini、NotebookLM、Antigravity（5 小时滚动窗口）与生态福利。遇到页面改版自动优雅降级，并支持手动校准与排序折叠。

月度防浪费提醒与本地备份

自动展示各平台已用占比进度条，距重置 ≤ 5 天自动提醒检查当月可消耗额度，并支持浅色/深色主题与纯本地 JSON 备份导出/导入。

安全与隐私边界

完全开源透明，严格遵循最小权限原则，让每一份数据只留在你的电脑里。

权限 / 机制 实际用途 安全边界
storage 将同步结果、手动校准与主题设置保存在本地 chrome.storage.local 零外发网络请求，不上传任何服务器
tabs 一键同步时复用单个后台非激活标签页并在提取完成后立即关闭 不读取其他无关标签页或浏览历史
alarms 支持低频定时自动刷新缓存（最低 1 小时，可随时关闭） 禁止高频轮询，不耗电不触发风控
官方 Google 站点域名 仅限 Google One、Cloud 结算、Builders Hub、AI Studio、Flow/Labs、Colab、Gemini、NotebookLM 可见文本提取 不申请 <all_urls>、cookies 或密码权限

快速安装与加载

支持让 AI 助手一句指令代劳、直接下载 ZIP 解压，或使用 pnpm 本地源码构建。

发给 AI 助手一键安装（Antigravity / Claude Code / Cursor / Codex）

直接复制下方指令发给你的 AI 编程助手，自动完成克隆、依赖安装与构建：

请帮我克隆 https://github.com/kirktools/google-ai-hub.git，使用 pnpm 安装依赖并构建出 dist 目录，然后告诉我如何在 Chrome 加载它。
1

下载 ZIP 或克隆构建

直接下载 google-ai-hub-chrome.zip 解压，或本地构建：

git clone https://github.com/kirktools/google-ai-hub.git
cd google-ai-hub
pnpm install && pnpm build
2

加载到 Chrome

打开 chrome://extensions/，启用右上角「开发者模式」，点击「加载已解压的扩展程序」，选中解压目录或 dist 文件夹。

3

固定图标并自动同步

将 Google AI Hub 固定到浏览器工具栏，首次打开自动静默识别你的 Google AI 套餐并汇总各平台余量，后续支持按小时低频自动更新。
