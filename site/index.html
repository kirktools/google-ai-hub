核心功能

专为 Google AI 订阅用户设计的省心体验，低频温和、开箱即用。

自动识别套餐，免手动配置

优先从 Google One 页面自动识别 Free / AI Plus / AI Pro / AI Ultra (5x / 20x) 及续费重置日，自动匹配对应权益卡片；未识别到时也支持设置页手动兜底。

一键静默同步 + 顺路被动更新

后台串行打开非激活标签页提取可见信息后立即自动关闭，不打断当前页面；内置 3 分钟冷却防抖，避免高频刷新；平时自己浏览这些站点也会顺路更新缓存。

8 大平台全景覆盖 + 手动校准

一站汇总 Google One、AI Studio、Flow、Colab、Gemini、NotebookLM、Antigravity（5 小时滚动窗口）与生态福利。遇到页面改版自动优雅降级，并支持手动校准与排序折叠。

三步本地构建与加载

使用 pnpm 构建，不到 1 分钟即可加载到你的 Chrome 浏览器。

1

克隆仓库并构建

拉取开源源码，使用 pnpm 安装依赖并生成 dist/ 目录。

git clone https://github.com/kirktools/google-ai-hub.git
cd google-ai-hub
pnpm install && pnpm build
2

加载到 Chrome

打开 chrome://extensions/，启用右上角「开发者模式」，点击「加载已解压的扩展程序」，选中项目中的 dist 文件夹。

3

固定图标并一键同步

将 Google AI Hub 固定到浏览器工具栏，点击「一键同步」即可自动识别当前 Google AI 套餐并汇总各平台余量。
